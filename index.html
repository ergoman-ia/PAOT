    인간공학 체크포인트 현황

    사용자 매뉴얼

    ILO 인간공학 체크포인트 132개를 기반으로 작업환경을 점검·개선하는 도구입니다.

    1. 기본 사용법

    • 보기 상단 전환 — 전문가용(132) / 관리자용 / 작업자용 / 픽토그램을 버튼 하나로 즉시 전환합니다. 작업자용과 픽토그램은 같은 20개 항목을 표로 보느냐 그림 카드로 보느냐의 차이입니다 — 업종·직종에 맞추어 자동으로 선정되며 양쪽이 항상 일치합니다.
    • 검색 — 상단 검색창에 단어를 넣으면 해당 문항만 걸러 보여줍니다.
    • 보기 버튼 — 그 항목을 개선할 구체적 아이디어를 확인합니다.
    • 조치여부 — 토글을 켜면 자동 저장되어 브라우저를 닫았다 열어도 유지됩니다.

    2. 메뉴 기능

    • 저장/불러오기 — 조치여부 상태를 CSV로 백업·복원합니다.
    • 체크포인트(인쇄용) 생성 — 작업자용·관리자용·전문가용 보고서를 즉시 만들어 인쇄합니다.
    • 맞춤 업종·직종별 체크포인트 생성 — 업종·직종을 넣으면 132개 문항이 그 현장 용어로 재작성된 전용 HTML 파일이 내려받아집니다. 생성에는 보통 60~100초가 걸립니다.

    3. 🖼 작업자용 픽토그램 체크리스트 (외국인 근로자용)

    132개 문항 중 작업자가 스스로 점검할 수 있는 85개를 뽑아, 글자를 못 읽어도 뜻이 통하도록 그림(픽토그램)과 짧은 한 문장을 붙인 화면입니다. ① 계측기·서류 없이 그 자리에서 판단할 수 있고 ② 회사 제도가 아니라 내 작업에 관한 것이며 ③ “아니오”일 때 스스로 고치거나·멈추거나·즉시 알리는 행동으로 이어지는 항목만 넣었습니다.

    • 답은 세 칸뿐 — ○ 잘하고 있음 / △ 고쳐야 함 / ✕ 해당 없음. 응답은 자동 저장됩니다.
    • 항목 선정 — 업종·직종을 고르면 그에 맞는 20개가 자동으로 선정됩니다. 작업자용 표와 픽토그램 카드는 항상 같은 20개입니다.
    • 🌐 표시 언어 — 한국어·영어는 항상 나오고, 고른 언어가 카드에 함께 나옵니다. ‘현장’ 표시가 붙은 언어는 그 업종·직종의 표현으로 번역된 것이며, 표시가 없는 언어를 고르면 확인을 누를 때 자동으로 그 현장 표현으로 번역됩니다.
    • 🖨 인쇄 — 그림 + 여러 나라 말 + ○△✕ 칸이 있는 카드형 점검표로 인쇄합니다. 「체크포인트(인쇄용) 생성」 메뉴에서도 같은 인쇄물을 뽑을 수 있습니다.
    • 언어 고르기 — 「맞춤 업종·직종별 체크포인트 생성」 창의 🌐 작업자용 픽토그램 체크리스트 언어에서 고용허가제 송출국 16개 언어를 여러 개 고를 수 있습니다. 132문항이 그 현장 용어로 재작성되면 픽토그램 문구도 같은 용어로 다시 쓰이고, 고른 언어는 그 문구를 번역합니다. 이미 만들어 둔 언어는 다시 번역하지 않고, 실패하거나 AI를 쓸 수 없으면 내장된 16개 언어 기본 번역이 대신 나옵니다. 고른 언어만 파일에 담기므로 현장에 있는 나라 말만 고르면 파일이 가볍습니다.

    4. 관리자용·작업자용은 어떻게 뽑히나요?

    관리자용 54개 — 기존 20개 직종의 검증된 선별 결과를 통계로 학습한 내장 우선순위표와 업종·직종 키워드 가중치로 계산하고, 맞춤 생성 때는 AI가 그 직종의 작업 특성을 보고 다시 고릅니다.

    작업자용 20개 — AI를 부르지 않고 코드가 정합니다. 위 85개 픽토그램 항목 안에서 ① 항목별 기본 중요도 ② 업종·직종 이름에 걸리는 규칙(예: 지게차·택배 → 운전석·안전거리, 조리·급식 → 미끄럼·고열·손씻기, 용접 → 국소배기·보호구) ③ 범주 키워드 가중치 ④ 검증된 우선순위표를 합산해 점수가 높은 순으로 뽑되, 한 범주에 몰리지 않도록 범주별 상한을 둡니다. 같은 업종·직종이면 언제나 같은 20개가 나옵니다.
