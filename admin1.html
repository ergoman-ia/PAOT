2접수된 파일 올리기

교육생이 메일로 보내온 cp-xxxxxxxx.json 파일을 여기에 끌어다 놓으세요. 여러 개를 한 번에 올려도 됩니다. 앱에서 "미등록분 모아서 내보내기"로 만든 묶음 파일(배열)도 인식합니다.

📥 여기에 파일을 끌어다 놓거나 클릭해서 선택

3공용 목록에 반영

A안은 버튼 한 번으로 GitHub에 바로 커밋됩니다(1~2분 뒤 전원 적용). B안은 파일을 내려받아 GitHub 웹페이지에 직접 올리는 방법입니다.

A안 — GitHub에 바로 반영 (권장)
토큰은 이 브라우저에만 저장되며 배포 파일에는 절대 포함되지 않습니다.
GitHub → Settings → Developer settings → Fine-grained personal access token에서 이 저장소 하나만 선택하고 Contents: Read and write 권한만 주세요. 그 외 권한은 불필요합니다.
B안 — 토큰 없이 수동 업로드

아래 버튼으로 파일을 내려받은 뒤, GitHub 저장소의 data/ 폴더에서 Add file → Upload files로 끌어다 놓고 Commit 하시면 됩니다. 덮어쓰기 됩니다.
